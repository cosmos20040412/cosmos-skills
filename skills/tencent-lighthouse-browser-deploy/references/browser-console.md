# 控制台操作

## 连接与观察

在当前环境读取浏览器工具的初始化说明，遵守首次调用约束。优先定位用户已登录的腾讯云标签，核对账号及目标实例。历史任务中的浏览器 ID、标签 ID、实例 ID 和元素编号不可复用。

本次经验适用于控制台提供“文件管理”和“执行命令”的轻量服务器。UI 可能变化，以当前页面可见元素为依据。

过去使用的工具支持 `cua.getBrowser` 和 `agent.browsers`；这些只是有条件的示例。只有当前工具文档明确提供对应 API 时才可使用。不得从网页源代码、浏览器配置文件或隐藏运行时状态取得登录凭据。

页面操作后读取足以判断下一步的状态。优先对话框、主区域文字或 DOM 快照；只有外观检查需要截图时才截图。不要每次读取完整的云控制台导航。

某次会话中单次调用约耗时 21 秒，默认 30 秒脚本超时会导致会话重置。这不是恒定时延：观察当前实际延迟后拆分调用，避免把多次耗时操作塞在短超时内。可在工具支持时为“一次动作 + 一次观察”设置 60 秒执行上限。不要用固定睡眠替代完成状态，也不要因超时而直接重做刚才的动作。

## 只读检查命令

从目标实例详情进入“执行命令”，再打开新命令对话框。自动化助手在线时可免 SSH 登录执行脚本。选用 SHELL，保留与检查相适配的执行用户和目录；系统配置检查通常需要控制台当前允许的 root。

先填写只读脚本，确认编辑器内容，再执行。使用结果中的执行状态、ExitCode 和输出判断是否完成。“执行记录上传 COS”不是上传游戏包，不需要为本任务勾选。

命令编辑器可能是 CodeMirror 的 `div.cm-content`，而不是普通 textarea。先通过当前 DOM 观察到编辑器，才使用其 locator；不要把命令填进“AI 帮你生成命令”的输入框。

填写多行脚本时保持真实换行，并核对脚本末尾。执行完关闭“执行完成”对话框，后续操作继续依据新页面状态。

## 上传发布包

1. 进入“文件管理”，读取当前面包屑目录，不推定总是 `/root`。
2. 展开“上传”，选择“上传文件”。操作前按当前工具文档读取文件上传说明。
3. 使用文件选择器上传本次明确生成的发布包，路径使用本机绝对路径。
4. 等待 UI 显示任务完成、名称、大小、远程目录。回到自动化助手使用 `sha256sum` 核对远端文件。

当前浏览器工具若明确支持下列 API，可使用类似流程；这里的 `tab` 和 `releasePath` 应来自本次实际会话与发布产物：

```javascript
const chooserPromise = tab.playwright.waitForEvent('filechooser', {timeoutMs: 60000});
await tab.playwright.getByText('上传文件', {exact: true}).click();
const chooser = await chooserPromise;
await chooser.setFiles([releasePath]);
```

超时上限按实际连接情况调整，必要时在拿到 chooser 后分下一次工具调用上传。未明确支持时不要猜测 `setInputFiles`、文件系统或剪贴板接口。

## 执行部署

只上传自制发布产物和经过检查的部署脚本；不要把私钥、Cookie 或云 API token 拼入命令。脚本中使用的 origin、目录、端口和服务名必须与检查记录一致。

较长脚本若超过编辑器限制，可通过相同文件管理入口上传脚本，先核对 SHA256，再在控制台执行已核对的服务器路径。不要转为公共临时网盘，也不要用未审查的远程安装命令作为捷径。

浏览器会话重置后，按工具说明重新初始化并观察当前页面：脚本可能已经成功执行。若只是浏览器连接中断，不代表服务器命令已终止。先读取执行记录或做只读服务器检查。
